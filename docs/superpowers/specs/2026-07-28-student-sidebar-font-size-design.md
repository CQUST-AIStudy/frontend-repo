# 学生端侧边栏字号调整设计

## 目标

解决学生端侧边栏菜单使用固定小字号、无法跟随全局根字号放大的问题，将侧边栏一级和二级菜单文字统一调整为 `15px`，提高可读性。

## 实现范围

- 修改 `src/views/student/Layout.vue` 中桌面端侧边栏的一级菜单、分组菜单和二级菜单字号。
- 同步修改移动端抽屉中的一级菜单、分组菜单和二级菜单字号。
- 仅调整菜单文字字号，不改变侧边栏宽度、菜单项高度、图标尺寸、间距、颜色或交互行为。
- 不调整教师端、管理员端或学生页面正文的字号。

## 方案选择

采用组件内定点修改：把学生侧栏菜单现有的 `text-[13px]` 和 `text-[12px]` 改为 `text-[15px]`。相比继续调整全局根字号，此方案能够直接作用于固定 `px` 样式，影响范围也最小。

## 验证

- 增加静态回归测试，确认桌面端和移动端侧栏不再保留 `12px`、`13px` 菜单字号，并且均包含 `15px` 字号。
- 执行相关导航测试。
- 执行生产构建，确认 Vue 模板和 Tailwind 样式可正常编译。
