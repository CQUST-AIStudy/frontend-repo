# 紧急实验卡片背景色调整设计

## 目标

将学生首页“当前最紧急的实验”卡片从浅橙色背景调整为柔和的浅红色，使其更准确地表达紧急或逾期状态，同时保持页面整体视觉克制。

## 设计

- 卡片背景使用浅红渐变：`#fff7f7` 到 `#fff1f2`。
- 卡片边框使用柔和红色 `#fecdd3`。
- 紧急标题、图标和倒计时标签改用协调的红色系，确保状态语义一致且文字对比度清晰。
- “继续修改”主按钮保留现有橙色主题，维持页面主操作的一致性。
- 其他卡片和页面模块不作修改。

## 验收标准

- 学生首页紧急实验卡片呈柔和浅红色，不再使用浅橙色背景。
- 紧急标题、图标、倒计时标签与新背景协调，且内容清晰可读。
- 主按钮、布局、数据展示和交互行为不变。
- 前端生产构建通过。
