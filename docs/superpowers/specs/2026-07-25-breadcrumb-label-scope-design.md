# 教师端与学生端面包屑标签范围设计

## 目标

教师端和学生端面包屑将 URL 静态路径段转换为中文页面名称，不向用户展示原始英文路径。管理端暂不纳入本次改动。

## 设计

- `src/utils/breadcrumbLabels.mjs` 只维护 `teacher` 和 `student` 两组标签。
- `resolveBreadcrumbs(role, path)` 保持通用接口：角色不存在或路径不属于该角色时返回空数组；动态 ID 等未映射路径段被忽略。
- 教师端和学生端布局继续调用该解析器，不修改管理端布局。
- 删除管理端标签配置，避免未完成能力被误认为已经支持。

## 测试

- 教师端覆盖单层静态路由及包含动态 ID 的多层路由。
- 学生端覆盖包含动态 ID 的多层路由。
- 测试不包含管理端断言。
- 修改后运行指定 Node 测试和生产构建。

## 非目标

- 不修改管理端面包屑。
- 不处理主题颜色或错题本工具栏测试失败。
- 不重构路由配置或布局结构。
