# 实验列表顶部进度概览设计

## 目标

将学生端实验列表底部占用较大纵向空间的“完成情况”区域移到实验列表上方，改为紧凑的横向概览卡，让学生进入页面后先看到整体进度，再浏览具体实验。

## 布局

- 概览卡放在状态标签栏之后、实验卡片列表之前。
- 桌面端采用单行布局：左侧显示“学习进度”、完成率和水平进度条，右侧依次显示总实验数、已完成、进行中、未开始。
- 窄屏下允许内容自然换行，统计项保持清晰的分组和可读间距。
- 删除页面底部原有的大型环形图和纵向统计列表，避免信息重复和无效留白。

## 视觉

- 延续页面现有白色卡片、浅色边框、圆角和轻阴影风格。
- 完成率使用现有主题橙色作为主要强调色，进度条轨道使用浅中性色。
- 已完成、进行中、未开始分别使用绿色、橙色和灰色辅助识别；总数保持中性文字色。
- 不增加新的图表或第三方依赖。

## 数据与交互

- 继续使用现有 `allExperiments`、`completedExperiments`、`inProgressExperiments`、`notStartedExperiments` 和 `completionRate` 计算结果。
- 状态标签筛选行为保持不变；顶部概览始终展示全部实验的总体数据，不随当前筛选标签变化。
- 空数据时所有数量和完成率均显示为 `0`，进度条宽度为 `0%`。

## 代码范围

- 仅修改 `src/views/student/ExperimentList.vue` 的模板、样式类和不再需要的图表逻辑。
- 移除该页面对 ECharts 的引用、图表 DOM 引用、初始化和销毁逻辑。
- 不修改接口、Store、路由或其他页面。

## 验证

- 增加或更新页面结构测试，覆盖概览卡位于实验列表之前、统计数据绑定、底部图表被移除以及筛选逻辑未受影响。
- 执行相关测试和前端构建。
