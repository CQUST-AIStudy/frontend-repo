# 登录页暖色主题改版设计

## 目标

将 `/login` 从深蓝科技风调整为与站内现有暖色主题一致的版本。以 `#cb8053` 为登录页主色，保留当前登录、注册、校验、动效和角色跳转等全部功能。

## 范围

- 只修改 `src/views/Login.vue` 的视觉表现与响应式布局细节。
- 保留登录与注册两个页签、学生/教师/管理员角色选择、密码显隐、记住密码、协议确认、错误提示和加载状态。
- 不修改 API、路由、状态管理、认证存储或后端代码。
- 不增加图片资源、字体或第三方依赖。

## 视觉方向

采用暖陶土色渐变背景与浅米色实体表单卡片：

- 主色：`#cb8053`。
- 页面底色：`#faf6ef`。
- 主要文字：`#3d3529`。
- 次要文字：暖灰色系。
- 辅助色：低饱和绿色，用于部分能力图标；错误和成功状态继续使用既有语义色。
- 圆角、细边框和低强度阴影沿用站内卡片语言。

背景以暖色渐变为主，并通过低对比度的代码括号、圆点和节点连线营造程序设计教学氛围。装饰只由 CSS 与现有图标构成，不影响内容可读性。

## 页面结构

### 桌面端

继续使用左右双栏布局：

- 左侧展示平台名称、定位文案和三项核心能力。
- 右侧展示登录/注册卡片。
- 品牌区与卡片保持清晰层级，主操作始终是视觉焦点。

### 平板与移动端

- 切换为单栏居中布局。
- 隐藏大面积背景装饰和三项能力列表，仅保留精简的平台标题与说明。
- 登录卡片适配窄屏；注册表单允许页面自然滚动，避免内容或提交按钮被裁切。

## 组件状态与交互

- 页签指示条、角色选中态、主按钮、复选框和输入框焦点环统一使用 `#cb8053` 及其深浅派生色。
- 输入错误继续显示红色边框与说明，不使用主色代替错误语义。
- 登录与注册切换动画、密码显隐、加载旋转和顶部提示保持现有行为。
- 悬停、按下和键盘焦点状态均清晰可见；减少动态效果的系统设置继续生效。
- 所有现有表单字段、校验规则、提交逻辑与跳转目标保持不变。

## 数据流与错误处理

本次不改变数据流。表单仍写入当前响应式状态，通过现有校验后调用既有 API，并由既有认证与路由逻辑完成登录跳转。注册、接口错误、协议未确认及字段校验错误继续沿用当前提示机制，仅调整提示容器的暖色主题适配。

## 验证

- 检查登录与注册页签切换及动画。
- 检查三个角色的选择状态和登录跳转逻辑未受影响。
- 检查密码显隐、记住密码、协议校验、字段错误和加载状态。
- 检查桌面、平板和手机宽度下的布局及注册表单滚动。
- 检查键盘操作和可见焦点。
- 执行 `npm run build`；条件允许时执行 `npm run lint`。

## 验收标准

- 登录页不再出现原有蓝色主视觉，主要交互色统一为 `#cb8053`。
- 页面与站内 `#faf6ef`、`#3d3529` 暖色体系自然衔接。
- 登录和注册功能、校验、提示与跳转行为无回归。
- 常见桌面和移动屏幕下无横向溢出、遮挡或不可操作区域。
