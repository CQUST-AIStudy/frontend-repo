# 隐藏老师端教辅工具侧边栏入口设计

## 目标

在老师端桌面和移动端侧边栏中隐藏“教辅工具”菜单组，同时保留其页面、路由和直接访问能力。

## 方案

老师端桌面和移动端侧边栏共用 `src/views/teacher/Layout.vue` 中的 `menuItems`。注释其中 `group: 'tools'` 的完整菜单配置，不修改通用菜单渲染逻辑，也不修改 `src/router/index.js` 中的页面路由。

这样只需改动一个菜单数据源，即可让两种侧边栏同步隐藏入口；恢复时取消注释即可。

## 验证

- 添加静态回归测试，确认 `tools` 菜单组处于注释状态且相关路由仍保留。
- 运行该测试。
- 运行前端构建，确认 Vue 模板和脚本仍可正常编译。

## 非目标

- 不删除教辅工具页面。
- 不禁用教辅工具路由。
- 不新增权限或功能开关。
