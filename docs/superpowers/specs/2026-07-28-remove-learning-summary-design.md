# 删除学情追踪练习情况摘要设计

## 目标

精简教师端学生提交详情的“学情追踪”页签，删除占用较多纵向空间的“练习情况摘要”卡片，让教师直接查看练习时间线。

## 范围

- 从 `LearningTracking.vue` 删除完整的“练习情况摘要”展示区域，包括 PTA 题目集表格和薄弱强化题集统计。
- 不把摘要中的题目集数量、提交数量、通过数量、得分或完成率迁移到时间线节点。
- 保留练习时间线现有的来源筛选、固定高度、内部滚动、渐变提示以及展开和收起交互。
- 保留接口响应和前端数据读取，避免扩大到后端接口变更；本次只调整前端展示。

## 页面状态

- 加载、错误和重试状态保持不变。
- 时间线有数据时按现有节点样式展示。
- 时间线无数据时继续展示现有空状态。

## 验证

- 增加前端结构测试，确认摘要标题和摘要表格不再渲染，时间线区域仍存在。
- 运行相关测试和前端构建。
- 确认项目 `.gitignore` 与 `.dockerignore` 状态符合仓库约定。

## 非目标

- 不修改学情追踪接口、数据库查询或返回结构。
- 不改变时间线节点字段、文案和排序。
- 不调整学生提交详情的其他页签。
