# 前端全局字号调整设计

## 目标

将前端页面的根基准字号从浏览器默认的 `16px` 调整为 `17px`，统一提升使用 `rem` 单位的文字可读性，同时控制对现有布局的影响。

## 实现范围

- 在全局基础样式的 `html` 规则中设置 `font-size: 17px`。
- 不改动各页面、组件中明确使用 `px` 的字号，避免按钮、表格、弹窗和固定尺寸区域出现大面积溢出。
- 不引入字号设置面板、响应式字号切换或其他额外功能。

## 影响与验证

使用 `rem` 的字号及相关尺寸会相对默认值放大约 6.25%；使用 `px` 的样式保持不变。修改后执行前端构建，确认样式可以正常编译；重点关注导航、表格、按钮及移动端布局是否因文本换行受到影响。
