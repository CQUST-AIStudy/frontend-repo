# 学情追踪时间线优化设计

## 目标

优化教师提交详情页的学情追踪时间线，避免大量记录撑高整个页面，同时提升判题结果的可读性并修正 PTA 得分颜色判断。

## 范围

- 仅修改前端 `LearningTracking` 组件及其直接测试。
- 不修改后端接口、请求参数和响应结构。
- 不调整练习情况摘要及提交详情页的其他区域。

## 交互设计

- 时间线默认使用约 520px 的最大高度，超出部分在区域内部纵向滚动，支持鼠标滚轮和触控板。
- 当当前筛选结果超过默认可视区域时，在时间线底部显示“展开全部 N 条”。
- 点击展开后取消高度限制，完整显示当前筛选下的全部记录；按钮变为“收起时间线”。
- 点击收起后恢复固定高度，并将时间线滚动位置回到顶部，避免用户回到一个不可预期的位置。
- 切换“全部 / PTA / LeetCode”筛选时自动恢复收起状态并回到顶部。
- 空状态沿用现有展示，不显示展开或收起按钮。

## 状态展示

判题结果使用中文标签，至少覆盖接口已知枚举：

| 原始状态 | 展示文案 | 色彩语义 |
| --- | --- | --- |
| `ACCEPTED` | 通过 | 成功绿 |
| `PARTIAL_ACCEPTED` | 部分通过 | 警示橙 |
| `MULTIPLE_ERROR` | 多处错误 | 错误红 |
| `WRONG_ANSWER` / `WRONG` | 答案错误 | 错误红 |
| `COMPILE_ERROR` | 编译错误 | 错误红 |
| `TIME_LIMIT_EXCEEDED` | 运行超时 | 警示橙 |
| `MEMORY_LIMIT_EXCEEDED` | 内存超限 | 警示橙 |
| `RUNTIME_ERROR` | 运行错误 | 错误红 |

未知状态不丢失信息，回退显示原始枚举值并使用中性色。

## 得分颜色

- PTA 记录以判题结果为准：`ACCEPTED` 的得分始终显示绿色，不再使用 `score >= 60` 判断通过。
- 明确失败的 PTA 记录显示红色，部分通过或资源限制类结果显示橙色。
- LeetCode 保留“通过为绿色、未通过为红色”的现有语义。
- 分数只负责展示数值，不推断题目满分或百分制及格线。

## 实现边界

- 在组件中维护展开状态和时间线容器引用。
- 将状态中文文案、标签样式和得分样式集中为可复用映射或纯函数，避免模板内继续叠加条件表达式。
- 不新增第三方依赖。

## 验证

- 先补充自动化测试，覆盖默认固定高度、展开/收起控件、中文状态映射以及 `ACCEPTED` 非 100 分仍为绿色。
- 执行相关测试、前端 lint 和生产构建。
- 在桌面宽度下检查滚动、展开、收起和筛选切换，不允许按钮或记录内容重叠。
